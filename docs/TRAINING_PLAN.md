## 第1天 — 7月26日（周六）「代码控制手」

**目标：WSL 里的代码能控制灵巧手、读到状态**

### 上午 (2h)

| 时间 | 任务 | 怎么做 |
|------|------|--------|
| 10:00-10:30 | USB 透传 | 管理员 PowerShell：`usbipd list` → `usbipd bind --busid X` → `usbipd attach --wsl --busid X` |
| 10:30-11:00 | WSL 确认设备 | `ls /dev/ttyUSB*` → `sudo chmod 666 /dev/ttyUSB0` |
| 11:00-12:00 | 启动驱动节点 | `ros2 run rh56f2_driver driver_node --ros-args -p port:=/dev/ttyUSB0`，另开终端 `ros2 topic echo /hand/state --once` |

### 下午 (3h)

| 时间 | 任务 | 怎么做 |
|------|------|--------|
| 14:00-14:30 | 测试读状态 | 反复 `ros2 topic echo /hand/state`，手扳手指看数值变化 |
| 14:30-15:30 | 测试写命令 | 发 HandCommand，先张开、再握拳、再对捏，确认手指跟着动 |
| 15:30-16:30 | 测试力控 | 设置力控40g，让拇指食指对捏碰到手掌就停 |
| 16:30-17:00 | 记录基础角度 | 张开状态 / 闭合状态 / 握镊子 / 握药勺 的角度值 |

### 验收标准
- [ ] `/hand/state` 有 6 个角度和力值
- [ ] 发 HandCommand 手指能动
- [ ] 力控触停有效（碰到手就停）
